# Official sources

- Normative WCAG 2.2 Recommendation: https://www.w3.org/TR/WCAG22/
- How to Meet WCAG 2.2 quick reference: https://www.w3.org/WAI/WCAG22/quickref/
- Understanding WCAG 2.2: https://www.w3.org/WAI/WCAG22/Understanding/
- Techniques for WCAG 2.2: https://www.w3.org/WAI/WCAG22/Techniques/
- WAI-ARIA Authoring Practices Guide: https://www.w3.org/WAI/ARIA/apg/

Treat WCAG success criteria as normative. Understanding documents, techniques, and APG examples are supporting guidance; a technique is not the only possible way to satisfy a criterion.
